# 테스트 쿼리 품질 점검 리포트

생성일: 2025-12-24
총 질문 수: 40개 (factual: 10, causal: 10, comparative: 10, deep_analysis: 10)

## 1. 전체 품질 평가

### ✅ 강점

1. **Intent 분류 명확성**: 각 질문이 query_type과 잘 매칭됨
2. **난이도 분포**: easy(13개), medium(11개), hard(16개) - 균형적
3. **수렴 노드 활용도**: comparative와 deep_analysis에서 2개 엔티티 질문 포함
4. **역사적 범위**: 삼국시대 ~ 대한제국까지 시대별 고른 분포

### ⚠️ 개선 필요 사항

1. **Factual 질문 다양성 부족**: 대부분 "언제", "누가", "무엇" 패턴
2. **Comparative 질문 불균형**: "차이"가 대부분, "공통점"은 3개뿐
3. **실제 온톨로지 데이터 매칭 필요**: 일부 엔티티가 TTL에 없을 가능성
4. **Deep Analysis의 모호성**: "분석하라", "설명하라" 등 추상적 표현

## 2. Query Type별 상세 점검

### 2.1 Factual (10개)

**목적**: 단순 사실 확인, 수렴 노드 덜 중요 (weight: 1.0)

| # | 질문 | 평가 | 개선 제안 |
|---|------|------|----------|
| 1 | 세종대왕이 훈민정음을 창제한 시기는 언제인가? | ✅ 적합 | - |
| 2 | 이순신이 참전한 전투는 무엇이 있는가? | ✅ 적합 | - |
| 3 | 경복궁은 누가 건설했는가? | ✅ 적합 | - |
| 4 | 광해군의 재위 기간은? | ✅ 적합 | - |
| 5 | 정약용이 저술한 책의 제목은? | ⚠️ 보통 | 온톨로지에 "저술" 관계가 있는지 확인 필요 |
| 6 | 임진왜란은 몇 년도에 발생했는가? | ✅ 적합 | - |
| 7 | 한석봉의 본명은 무엇인가? | ⚠️ 위험 | "한석봉" 엔티티가 TTL에 있는지 확인 필요 |
| 8 | 병자호란 당시 조선의 왕은 누구인가? | ✅ 적합 | - |
| 9 | 불국사는 어느 시대에 건립되었는가? | ⚠️ 보통 | "불국사" 엔티티가 TTL에 있는지 확인 필요 |
| 10 | 을사조약은 언제 체결되었는가? | ✅ 적합 | - |

**Factual 총평**:
- 대부분 적합하나, **온톨로지 데이터 범위 확인 필요**
- "한석봉", "불국사", "정약용의 저술" 등은 HistoK TTL에 없을 가능성
- 권장: 실제 TTL 파일에서 엔티티 존재 여부 확인 후 교체

**개선 제안**:
```json
// 대체 질문 예시
{
  "query": "명성황후는 어디에서 시해되었는가?",
  "query_type": "factual",
  "intent_keywords": ["어디", "시해"],
  "expected_entities": ["명성황후"],
  "difficulty": "easy"
}
```

### 2.2 Causal (10개)

**목적**: 인과관계 분석, 수렴 노드 중요 (weight: 1.5)

| # | 질문 | 엔티티 수 | 평가 | 수렴 노드 활용 |
|---|------|-----------|------|----------------|
| 1 | 임진왜란이 발생한 원인은 무엇인가? | 1개 | ✅ 적합 | 중간 |
| 2 | 세종대왕이 훈민정음을 창제한 이유는? | 2개 | ✅ 적합 | 높음 |
| 3 | 인조반정이 일어나게 된 배경은 무엇인가? | 1개 | ✅ 적합 | 중간 |
| 4 | 고려가 몽골에 항복한 이유는? | 2개 | ✅ 우수 | 높음 (2개 엔티티) |
| 5 | 병자호란의 결과로 조선에 어떤 영향을 끼쳤는가? | 2개 | ✅ 우수 | 높음 (2개 엔티티) |
| 6 | 정조가 수원 화성을 건설한 목적은? | 2개 | ✅ 적합 | 높음 |
| 7 | 갑신정변이 실패한 원인은 무엇인가? | 1개 | ✅ 적합 | 중간 |
| 8 | 신라가 삼국을 통일할 수 있었던 이유는? | 2개 | ✅ 우수 | 높음 |
| 9 | 동학농민운동이 확산된 배경은? | 1개 | ✅ 적합 | 중간 |
| 10 | 조선시대 당쟁이 격화된 원인은 무엇인가? | 2개 | ✅ 적합 | 높음 |

**Causal 총평**:
- 매우 우수한 질문 구성
- 2개 엔티티 질문이 6개 → 수렴 노드 평가에 적합
- "원인", "이유", "배경", "목적", "결과" 등 다양한 인과관계 패턴

**수렴 노드 중요도 분석**:
- 1개 엔티티 질문 (4개): 수렴 노드 발견 어려움 (예: "임진왜란 원인" → 확장 필요)
- 2개 엔티티 질문 (6개): 수렴 노드 발견 용이 (예: "고려 ↔ 몽골" 연결점)

### 2.3 Comparative (10개)

**목적**: 비교 분석, 수렴 노드 매우 중요 (weight: 1.2)

| # | 질문 | 비교 유형 | 평가 | 수렴 노드 활용 |
|---|------|-----------|------|----------------|
| 1 | 임진왜란과 병자호란의 공통점은 무엇인가? | 공통점 | ✅ 우수 | 매우 높음 |
| 2 | 세종대왕과 정조의 업적을 비교하면? | 일반 비교 | ✅ 우수 | 매우 높음 |
| 3 | 갑오개혁과 갑신정변의 차이점은? | 차이점 | ✅ 적합 | 높음 |
| 4 | 신라와 고구려의 건국 과정의 유사점은? | 유사점 | ✅ 적합 | 높음 |
| 5 | 훈민정음과 한자의 차이는 무엇인가? | 차이점 | ⚠️ 보통 | "한자" 엔티티 없을 가능성 |
| 6 | 이순신과 권율의 전략 차이는? | 차이점 | ✅ 적합 | 높음 |
| 7 | 조선 전기와 후기의 정치 체제 차이는? | 차이점 | ⚠️ 어려움 | "조선 전기/후기" 시대 구분 모호 |
| 8 | 백제와 신라의 불교 수용 방식 차이는? | 차이점 | ✅ 적합 | 높음 |
| 9 | 경복궁과 창덕궁의 건축 양식 차이는? | 차이점 | ✅ 적합 | 높음 |
| 10 | 동학과 천주교의 사상적 공통점은? | 공통점 | ⚠️ 보통 | "동학", "천주교" 엔티티 확인 필요 |

**Comparative 총평**:
- "차이/차이점" 질문이 7개, "공통점/유사점" 질문이 3개 → **불균형**
- 모든 질문이 2개 엔티티 → 수렴 노드 평가에 최적
- 일부 질문은 온톨로지 범위 초과 가능성 (한자, 천주교, 동학)

**개선 제안**:
```json
// "공통점" 질문 추가
{
  "query": "명성황후와 민비의 공통된 정치 활동은?",
  "query_type": "comparative",
  "intent_keywords": ["공통", "정치"],
  "expected_entities": ["명성황후", "민비"],
  "difficulty": "medium"
}
```

| 5 | 실학사상의 발전 과정과 조선 후기 사회 변화의 관계를 분석하라 | 2개 | ⚠️ 어려움 | 매우 높음 |

  "intent_keywords": ["업적", "영향"],
  "expected_entities": ["세종", "조선"],
  "difficulty": "hard"

## 3. 온톨로지 데이터 매칭 점검 (필수)

| 엔티티 | 질문 개수 | 존재 가능성 | 우선순위 |
|--------|-----------|-------------|----------|
| 한석봉 | 1 | 낮음 | ⚠️ 교체 권장 |
| 불국사 | 1 | 중간 | 확인 필요 |
| 정약용 | 1 | 중간 | 확인 필요 |
| 권율 | 1 | 중간 | 확인 필요 |
| 한자 | 1 | 낮음 | ⚠️ 교체 권장 |
| 동학 | 1 | 낮음 | ⚠️ 교체 권장 |
| 천주교 | 1 | 낮음 | ⚠️ 교체 권장 |
| 실학 | 1 | 낮음 | ⚠️ 교체 권장 |
| 민란 | 1 | 낮음 | 구체적 사건명으로 교체 |

## 4. 수렴 노드 활용도 분석

### 4.1 Query Type별 수렴 노드 중요도

| Query Type | 가중치 | 2개 엔티티 질문 수 | 수렴 노드 활용도 |
|------------|--------|-------------------|-----------------|
| factual | 1.0 | 0개 / 10개 | 낮음 (의도적) |
| causal | 1.5 | 6개 / 10개 | 높음 ✅ |
| comparative | 1.2 | 10개 / 10개 | 매우 높음 ✅ |
| deep_analysis | 1.3 | 8개 / 10개 | 높음 ✅ |

**총평**:
- Comparative는 100% 2개 엔티티 → 수렴 노드 평가 최적
- Causal, Deep Analysis도 60~80% → 적합
- Factual은 의도적으로 0% → 적합 (수렴 노드 덜 중요)

### 4.2 수렴 노드 발견 예상 질문 (TOP 10)

1. **임진왜란과 병자호란의 공통점** → 수렴 노드: "조선", "침략", "전쟁"
2. **세종대왕과 정조의 업적 비교** → 수렴 노드: "조선", "개혁", "문화"
3. **고려가 몽골에 항복한 이유** → 수렴 노드: "전쟁", "외교", "강화도"
4. **병자호란의 결과로 조선에 끼친 영향** → 수렴 노드: "조선", "청나라", "조약"
5. **신라가 삼국을 통일한 이유** → 수렴 노드: "당나라", "외교", "백제", "고구려"
6. **갑오개혁과 갑신정변의 차이** → 수렴 노드: "개혁", "일본", "청나라"
7. **이순신과 권율의 전략 차이** → 수렴 노드: "임진왜란", "전쟁", "전략"
8. **백제와 신라의 불교 수용 방식 차이** → 수렴 노드: "불교", "고대", "문화"
9. **임진왜란이 조선 사회에 끼친 영향** → 수렴 노드: "조선", "일본", "전쟁"
10. **조선시대 당쟁의 전개 과정** → 수렴 노드: "조선", "정치", "붕당"

## 5. 최종 권장 사항

### 5.1 즉시 조치 (Step 1 전 필수)

1. **온톨로지 데이터 확인**:
