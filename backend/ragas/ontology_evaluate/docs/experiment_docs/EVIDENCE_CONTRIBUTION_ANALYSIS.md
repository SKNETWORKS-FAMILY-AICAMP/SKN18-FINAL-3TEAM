## 5. 쿼리 타입별 특성 분석

### factual (사실 확인형)
```
특징: 소수의 핵심 정보가 중요
- 상위 2개: 평균 0.63 (최고점)
- N=5 이후 급격히 하락
- 기여함 25%, 간접기여 59%

권장: N=4~5
이유: 핵심 사실 몇 개만 있으면 충분
```

### causal (인과관계형)
```
특징: 원인-결과 연결 정보 필요
- 상위 1개: 평균 0.60 (최고)
- N=5까지 0.48 유지
- 기여함 22%, 간접기여 51%

권장: N=5~8
이유: 인과 연결을 위해 적당한 맥락 필요
```

### comparative (비교형)
```
특징: 간접기여 중심, 직접 기여 없음
- 기여함 0% (!) 
- 간접기여 66~72%
- 전체적으로 낮은 점수 (0.33~0.39)

권장: N=7~10
이유: 직접 답이 없어 다양한 간접 정보 필요
특이점: 확장보다는 비교 대상 자체 정보가 중요할 수 있음
```

### deep_analysis (심층 분석형)
```
특징: 다양한 정보가 모두 유용
- 평균 점수 0.81~0.90 (압도적)
- 기여함 65~76%
- 유용 비율 96~100%
- N=15까지도 점수 유지

권장: N=10~15
이유: 다양한 관점의 정보가 모두 기여
```
