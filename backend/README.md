# Django Backend

이 디렉터리는 Django 기반 API 서버 및 웹 애플리케이션 코드를 위한 공간입니다.

- `apps/`: Django 앱과 도메인별 모듈을 배치합니다.
- `config/`: 프로젝트 설정(`settings.py`, `urls.py`)을 배치합니다.
- `tests/`: Django 단위/통합 테스트를 배치합니다.
- `scripts/`: 관리 명령이나 배포 스크립트를 배치합니다.

> 아직 구현 파일이 없으므로 빈 폴더로 남겨두었습니다. Django 프로젝트를 생성할 때 `django-admin startproject config django_app`과 같이 이 디렉터리 안을 루트로 삼아주세요.
